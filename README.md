## Description

This project is an AI Research Assistant that allows users
to upload research papers in PDF format and ask questions
about their contents.

The system uses Retrieval-Augmented Generation (RAG) to
retrieve relevant sections from the uploaded research paper
and provide them to an AI model for generating answers.

## Features

- PDF upload
- PDF text extraction
- Text chunking
- Text embeddings
- Hybrid semantic and keyword retrieval
- AI question answering
- Chat history
- Retrieved source display
- Clear chat option

## Technologies

- Python
- Streamlit
- PyPDF
- Sentence Transformers
- Scikit-learn
